# Aprende las Letras — Juego Educativo

Juego web interactivo para aprender el abecedario, encontrar letras, formar palabras y completar palabras, diseñado para niños y dispositivos móviles.

## Características
- **Totalmente responsivo**: se adapta a móviles, tablets y escritorio.
- **Modos de juego**:
	- El Abecedario: explora letras, palabras y emojis.
	- Encuentra la Letra: identifica la letra correcta.
	- Aprende Palabras: visualiza y escucha palabras.
	- Completa la Palabra: elige la letra faltante.
- **Soporte táctil**: botones y tarjetas optimizados para uso con el dedo.
- **Personalización de fondo**: sube o enlaza una imagen de fondo.
- **Síntesis de voz**: escucha letras y palabras (requiere navegador compatible).

## Estructura de carpetas
```
├── index.html           # Página principal del juego
├── css/
│   └── style.css        # Estilos responsivos y animaciones
├── js/
│   └── script.js        # Lógica de los modos de juego
├── assets/
│   └── icon.svg         # Icono del juego (puedes agregar más imágenes)
└── README.md            # Esta documentación
```

## Cómo usar
1. Descarga o clona el repositorio.
2. Abre `index.html` en tu navegador (Chrome, Edge, Firefox, Safari).
3. ¡Juega y aprende! Usa los botones para cambiar de modo.

### Personalización
- Cambia el fondo desde la pantalla principal (sube imagen o pega URL).
- Elige la voz para la síntesis desde el selector de voz.
- Puedes editar `js/script.js` para agregar más palabras o emojis.

## Requisitos
- Navegador moderno (recomendado: Chrome, Edge, Firefox, Safari).
- Para síntesis de voz: soporte de Web Speech API (la mayoría de navegadores actuales).
